# CraneCalc

Crane runway calculation workspace with a moving-wheel-load beam solver, live LaTeX worksheets, source verification register, project files, and validated report/SVG/DXF export.

## GitHub Pages

The static build runs calculations and creates reports entirely in the browser. Project inputs remain in browser storage on the current device; export a project JSON file to move between devices or between the local and hosted versions. The site is public, but saved project inputs are not uploaded to GitHub.

```sh
npm ci
npm run build:pages
npm run preview:pages
```

Open http://127.0.0.1:4175. After validation, **Generate output** recalculates the captured inputs in a separate worker and opens the output panel. Select **Open report · Print / Save PDF**, then use the report's print control. Use Chrome or Edge, 100% scale, background graphics enabled, and browser headers/footers off; each calculation page prints its own header and footer (project, calculation revision, issue status, prepared/checked/engineer of record and PAGE n OF N), and page 01 carries the responsibility and seal block. Reports retain Letter calculation pages and ARCH D drawing page definitions; verify the saved PDF's page sizes because browser print capabilities vary. Printable HTML includes embedded equation fonts and can also be downloaded for offline review. SVG, DXF, JSON and interface CSV downloads remain available.

`.github/workflows/pages.yml` tests and builds the static site on pushes to `main`, then deploys it to GitHub Pages. Set the repository's **Settings → Pages → Source** to **GitHub Actions**. No API key, server, database, or secrets are required. Relative asset paths support both repository Pages URLs and custom domains. Only `dist` is published; source reference files, generated local reports, and private attachments are not web assets.

The static and local versions use the same calculation engine and report renderer. Invalid, incomplete, unverified and unsupported results block export; verified failed checks remain visible in exportable reports. Publishing the application does not expand its engineering scope or certify a design.

## Current calculation capability

The app now includes an **AIST runway girder design worksheet** referenced to **AIST Technical Report 13** using the user's supplied source dated February 24, 2020, DG7 third edition (2019, appended 2023 corrections), and directly verified AISC 360-16 provisions. Exact source provenance is retained in the source audit; the reference building requires its own design.

- One to six simple/continuous bays, one to three ordered crane trains, manufacturer wheel schedules, refined moving-load analysis, US/SI conversion and AISC W-shape catalogue.
- AIST LRFD/ASD runway combinations, separate crane dead/lift/impact components, absent/empty/loaded crane states, single-crane horizontal actions, minimum impact/side-thrust/traction rules and manufacturer bumpers.
- Compactness, compact symmetric I-girder F2 LTB/flexure, rail-head flange force couple, longitudinal compression and concurrent H1 interaction, F13 actual net-flange rupture, G2 web shear without tension field action.
- Local wheel/support yielding, crippling, sidesway/compression buckling; actual bearing inputs; one selected girder fatigue material point and resistance; single-crane AIST deflections, each bay against its own span, at the most restrictive of the owner limit, the AIST building class and the crane's CMAA service class (DG7: L/600 for A to C, L/800 for D, L/1000 for E and F); minimum thickness, clip/pad spacing, hook-bolt and bracket suitability.
- Brace strength/stiffness requirements and connection bolt-pitch/weld direct-shear screening, with full system/connection models explicitly distinguished.
- Server-revalidated PDF/SVG/DXF exports from an immutable revision. Supplied-load analysis reports remain available.

**Complete design export remains gated** by actual torsion/warping/load-height stability, brace-system adequacy and complete bearing/end/tieback/longitudinal connection models. Generic source equations and representative 3D bolts cannot verify these. Noncompact flexure and special long-span/guide-roller/overlapping-wheel cases remain unsupported. Catalogue capped W girders now have the separate bounded design branch described below. Disabling connection templates does not waive required checks.

See [implementation and limitations](references/AIST_CHECKS.md) and [source identities, hashes and clause locations](references/SOURCE_REGISTER.md). Source status reflects the supplied full texts; unresolved project inputs/models are not mislabeled unavailable sources.

## Generating output

1. Replace the illustrative geometry, crane schedule and criteria with project inputs.
2. Choose **Criteria → Report scope → Supplied-load analysis & user criteria** for an analysis-only report. AIST design scope requires actual project data and all applicable engineering models before design export.
3. Resolve input errors and ensure equilibrium and both refinement checks pass. Failed user serviceability checks may be exported and are identified in the report.
4. Click **Generate output**. The local service downloads the PDF; GitHub Pages offers a printable report with **Print / Save PDF**. Both versions offer individual SVG downloads and layered CAD linework DXF. Live diagram previews are available before export.
5. Changing inputs triggers recalculation and retains an existing generated report as an explicitly identified previous revision.

Analysis reports explicitly exclude code compliance, strength, torsion/warping, fatigue, bracing and connection adequacy. Lateral bending deflection is not rail displacement including twist. Code load factors are not applied even when the project method selector is LRFD or ASD. The shortest-span deflection limit is applied conservatively to a global multi-span deflection envelope. Continuous supports are assumed to resist any calculated uplift; actual hold-down design is excluded.

## Engineering implementation

Canonical units are mm, N, MPa and kg/m³. `src/engine` holds the shared project schema, solver, validation, properties, reference register and immutable snapshot types. The UI calculates in a cancellable Web Worker; `server` independently checks the same engine before rendering escaped HTML to PDF in a network-isolated Chromium page.

Beam elements use exact elastic stiffness, consistent arbitrary-position point-load vectors and uniform-load vectors. Nodal deflections are recovered by Cholesky solution. Point-load moments and shear discontinuities are also evaluated at wheel locations. Moving-load positions are sampled and refined, with exact axle/support crossing positions added. Each crane, and each pair of neighbouring cranes, also gets its absolute-maximum-moment positions on every span (a wheel and the resultant of the wheels on the span equidistant from midspan). Neighbouring cranes are additionally placed at closest approach to one another; those coupled positions pair only with their partner, so they add cases linearly instead of multiplying the search. The result is a converged sampled envelope, not proof of an exact multidimensional global maximum. Repeated bay load states in the detailed lateral/torsional model reuse their solution. Lateral restraints are rigid, not springs. Shear deformation and nonlinear effects are excluded. The default allowable refinement change is 1%; equilibrium tolerance is 1e-7 relative to applied loads.

The detailed runway model also checks major flexure for wheels at the rail head in the inelastic range. Each strength case's 0.8-stiffness eigenvalue gives an elastic critical moment, Mcr = λM/0.8, that includes load height, the UDL at rail height, axial load, the moment diagram and the modeled tie and bearing stiffness. Mcr is converted to an equivalent unbraced length through F2-4 (rolled) or F5-4 with the compression-flange rt (capped). The available F2/F5 strength is then taken at max(Lb, L_e), so moment gradient never earns credit above Cb = 1. The solver reproduces the Clark and Hill load-height coefficients (ENV 1993-1-1 Annex F) within 1.5%.

Analysis-scope longitudinal demand is descriptive. AIST design applies the single-crane traction or bumper term; actual longitudinal connections/load paths remain separate.

The typical section is cut at mid-bay (marked on the plan) looking back at the frame on a grid: both runways with the girders and rails cut, the columns and brackets beyond, the crane span and column-to-rail dimensions, and the T.O.R., T.O.S. and bearing seat elevations. Only the runway band is drawn, with the columns broken above the rail and below the bracket, because the building heights are reference geometry; a wide crane span is shortened by a break (its dimensions keep their true values), so the runways draw at 1/2" = 1'-0" or 1:20 to 1:25 for the demonstrations. Every view title carries a detail bubble; references between sheets resolve to *detail/sheet* when the set is assembled. Existing and reference construction is dashed; new steel is solid.

**Detail sheets** follow from **S-02**: the details that apply are laid out on a module grid of three columns of cells about 9.4 in wide in four rows (three taller rows when a sheet needs no more), each detail centered in its cell with its numbered bubble, title and printed scale beneath it (in the taller cells of a three-row sheet a detail takes the next standard scale when it still fits and no text then overlaps text or linework), and a notes column at the right holding the sheet notes and the notes and tables of every group of details on the sheet. The groups, in order, are the girder-side connections (girder bearing and column bracket, bolted end bearings with an enlarged section through a sleeved sliding bolt, or the end template, the flange tie when no direct flange ties are designed, the rail keeper with the keeper spacing and rail joint, and the rail joint layout), the cap channel section and end development, the independent girder supports (adjacent girder ends, and the small-scale flange tie plan and bearing movement diagram only when no direct flange tie plan or bolted end bearing detail draws them larger), the welded or existing column brackets, the direct flange ties, the bolted runway end stops (elevation, plan, section at the face and design data) and the new freestanding runway columns (column elevation over two rows, base plate plan, footing plan and section, design data and foundation notes). Fabrication dimensions are on the details: the direct flange tie section chains the girder-end bolt edge and pitch, dimensions the vertical bolt gauge, sizes both gussets and shows the release filler; the tie plan locates each tie from its bearing stiffener and the stiffener from the girder end; the rail keeper detail dimensions the keeper lip over the rail base, the clearance to it and the keeper width; capped bearing stiffeners carry a CJP groove callout at the W top flange and are fitted at the bottom. The rail joint layout plans both runway rails along the grids with every rail piece and joint dimensioned: pieces are 39 ft mill lengths or cut to whole inches (10 mm) and at least 10 ft long, joints stay 2 ft clear of girder joints and of the opposite rail's joints at every wheel spacing of a crane, the runway B rail starts with a half length so its joints fall between those of runway A, and at a continued end the new rail joins the existing rail cut back 2 ft beyond the grid. Sections are keyed on their parent views by cut marks carrying the section's detail/sheet: the flange tie section on the tie plan, the saddle section on the flange tie section, the end stop section on the end stop plan and the sliding bearing bolt section on the bearing plan (a cut along the far-side sliding bolts, looking outboard). Groups follow one another in reading order, continuing onto the next row, so a sheet has no holes and any spare cells fall at its end. A group is never split between sheets; the set uses as few detail sheets as fit, balanced so the emptiest is as full as it can be: one sheet of twelve details for the rolled demonstration, and two for the capped and new-column demonstrations. Sheet titles name their groups, and every reference between details resolves to *detail/sheet* when the set is assembled. Text prints at standard heights: 1/8 in labels, dimensions and notes (no text under 0.09 in), 3/16 in detail titles; S-00, S-01 and the detail sheets lay out their text and linework at printed size, with 0.46 mm object lines, 0.25 mm hidden lines in short black dashes, existing work screened in long dashes, and finer leaders and dimensions; both-sides fillet symbols carry the size on each side of the reference line. Leaders land on the label end facing their target and are ordered so they do not cross. The title block carries the engineer of record, revisions and the issue status; sheets read PRELIMINARY - NOT FOR CONSTRUCTION until the calculation validates with no failed checks, the engineer of record, an issue purpose and the adopted building code are entered and, where the calculation leaves part of the supporting structure unchecked, the engineer's evaluation of it is referenced. The title block carries the project site address, and output without an entered revision is revision P1.

**Bracket design forces** are one factored envelope table per set, titled with the design method and giving the AIST combination number of every value. For each grid it lists the largest combined reaction V with its concurrent left and right girder end reactions and seat moment, the largest seat moment with its V where that is a different case, and the least girder end reaction (negative is uplift), then the horizontal forces as concurrent cases: the largest longitudinal force at the locating bearing with the lateral forces of the same case, and the largest top-flange lateral force with its own longitudinal and bottom-flange forces. H TOP and H BOTTOM of one case act together; H BOTTOM is signed relative to H TOP (negative: opposite, a couple). Crane traction acts in either direction (±) at the locating end of every bay the crane is on. The crane stop force acts only on an end bay that carries a stop, with the crane on it, toward the stop, and is delivered at that bay's locating end: grid 1 for a stop at the left runway end and the last bay's lower-numbered grid for one at the right end, signed + toward the higher-numbered grid. A continuous girder with bolted bearings delivers it at its locating support. The envelope covers every strength combination and crane position of the analysis, each bay that carries the longitudinal force with its end couple, and a wheel over a shared grid bearing on either girder end, so symmetric runways give mirror-image vertical values; ± marks a seat moment reached in both directions. The seat moment ΣV·e takes each reaction at 0.8 of the bearing length from its girder end, as the bracket design does, and the welded bracket is checked for every concurrent case of the same envelope. The welded bracket's seat plate is also fillet welded along its top across the column flange (field weld to an existing column): the bearing bolts bring the locating end's longitudinal force and H BOTTOM into the seat, and the seat fillet with the rib root fillets is checked as one elastic weld group under every concurrent case with its vertical load (the seat line's share of the bracket moment included), with the J2.4 minimum, the column flange (J10.1) and web (J10.2) under the seat's pull and the fillet's fatigue. The fillet is the smallest standard size from the J2.4 minimum that carries these forces, or the entered collector fillet with designed crane-level bracing. The bracket plan shows the bearing plates and their bolt holes on the seat (ordinates from the grid, rows at the bearing gauge) and keys the transverse section and the elevation. The table is drawn with the bracket details, else with the independent supports when the bracket is by others (on the cover for a continuous runway on brackets by others); the other details, the cover and the deferred-submittal list refer to it. Calculation page 04A carries the same envelope with case IDs.

Drawing dimensions use feet and fractional inches in US mode, with small plate/bolt sizes in fractional inches; SI drawings use millimeters. Under **Project**, enter the originator, checker, floor datum, top-of-rail elevation (unless the existing column survey sets it), engineer of record, issue purpose and revision rows. Preview the sheets under **Drawings**, or download their individual SVGs from Generated output. Calculation pages remain Letter size.

## Existing building checks

**Bolted end bearings** (Connections): each girder end is bolted through its bottom flange, bearing plate and bracket seat with four bolts in two rows at the bearing plate ends. The left end of each bay locates with standard holes and pretensioned slip-critical bolts that carry the factored longitudinal force, the bottom-flange tie force and uplift. The right end slides in slots in the girder flange under plate washers. Its bolts are pretensioned against steel sleeves that pass through the slots, so the flange is not clamped and still slides: AISC J1.10(c) requires pretensioned bolts at crane supports in buildings with cranes over 5 tons. The sleeves carry the transverse force in bearing on the slot sides and the washers take uplift into the bolts. Snug-tight bolts with jam nuts (long slots within the J3.2 2.5d limit) remain selectable for cranes of 5 tons or less and are checked against that limit. Checks cover bolt slip, shear, tension and bearing, sleeve installation load and length, flange bearing on the sleeves, washer bending, flange and seat prying, edge distances and spacing, and nut clearance to the web fillet, bearing stiffeners and bracket ribs. The bolted bearing replaces the girder-end cover plates and restrains the bottom flange laterally, so the paired-bar tie is needed at the top flange only; the analysis models that bottom restraint through the bolts' shear stiffness. Drawn with the connection details (shared support elevation and bottom-flange hole plan) and on SK-05, with an enlarged section through one sliding bolt: a headed ASTM F3125 bolt set from above, its head on the plate washer and its A563 DH nut and F436 washer below the seat as the turned element, with the grip (plate washer, sleeve, bearing plate and seat) and the ordered length (grip plus the AISC length to add and one washer, to the next 1/4 in), or "length to suit seat" with the known grip when the seat is by others. The 1/16 in washer clearance is a leader note. A continuous girder is bolted the same way at every support: the support nearest mid-length locates and all the others slide, with slots sized for the sliding allowance, which is checked against the thermal travel from the locating support plus end rotation and setting tolerance (the sliding allowance and temperatures are entered with the bearing). The detail draws an interior sliding support and the locating support with the girder running through, each under its own grid bubble, and states every sliding grid and the runway-end condition (girder ends at the grid, bearing plate from the girder end); a two-span girder, which has no interior sliding support, is drawn sliding at its runway end with the girder ending at the grid. The girder schedule names the locating grid. Without bolted bearings the girder web end connection is drawn as two cover plates bolted through the web and fillet welded at their outer faces to a column-side end plate, which with its column attachment (and, on a continuous girder, a thermal release at one end) is by the building designer.

**Girder-side tie gusset** (paired flat-bar ties without a direct flange saddle): the girder gusset lies in the plane of the tie-side bearing stiffener and is CJP welded to its outer edge just inside the tied flange; the bars start clear of the stiffener and the full-depth stiffener pair carries the tie force into the girder as the restraint diaphragm. Checks cover the CJP (base metal in tension or compression), its Category C fatigue, the gusset fit between the flanges, bar clearance to the stiffener and the unbraced gusset length. The flange tie / column connection plan draws the stiffeners and the parts under the flange hidden, breaks the bars between their bolt groups, and calls the CJP with a groove symbol.

**Direct flange saddle** (paired flat-bar ties on simple spans): a saddle plate under the tied flange runs from the web gap (clear of the rolled root) to the flange tip, and the girder gusset hangs from it. The saddle is welded to the flange only by two transverse end fillets across the flange, one at each saddle end, each the full saddle width; its edges along the runway are not welded (one is flush with the flange tip, the other is beside the rolled root). The saddle-weld check uses exactly those two welds: their length, their spacing (the saddle length), the tie force along them and its moment as throat normal stress along each weld. The toe of each end fillet on the flange is in the fatigue register as an AISC Table A-3.1 item 7.1 short attachment (Category D for the 4 in saddle), with the local flange strip range added. The bars stop below the toe of the gusset-to-saddle fillets (the weld leg plus 1/16 in, rounded up to 1/8 in) and 1/2 in short of the column flange, which the column gusset spans. The column gusset height is the slot pattern plus the minimum edge and a 1/16 in slot location tolerance beyond each slot, rounded up to a 1/4 in cutting increment; the root welds run its full height. On a capped girder the girder gusset is checked for 1/2 in clearance to the turned-down cap channel flange. The drawings give one AWS A2.4 symbol per joint with its size and length (saddle to flange at each end, gusset to saddle on both faces, column gusset root on both faces), chain each bar-end hole group with its closing edge distance, draw the column flange (dashed when existing) and the cap channel in the transverse section, plan and saddle section, and show the bars, filler and bolts that clamp the gusset in the saddle section. SI sheets read these details to the millimetre (half millimetre under 25 mm) with stresses in MPa.

**Tie movement** (paired flat-bar ties): the bars are fixed in the girder bolt group and must follow the girder. Single-crane support rotation moves each bar along the runway by up to θ·d every cycle; factored rotation plus thermal travel α·L·ΔT at sliding ends (on a bolted continuous girder, over the distance from the locating support) sets the static movement. The checks cover Category B fatigue at the bolt groups with that cyclic out-of-plane bending, AISC H1-1 for each bar under the tie force with the imposed-movement moments (thermal as a self-straining load, factor 1.0), out-of-plane bending of both gussets and their root welds, root fatigue, and bar slenderness (K = 0.8 between the inner bolt rows). At the column end each bolt can be pretensioned against a steel sleeve passing through a vertical slot in the column gusset, which releases support deflection without clamping the gusset; slot travel, sleeve load and length, gusset bearing, net section, block shear and edge distances are checked. Direct flange saddles also work where the bracket is by others: enter the column face distance, and the package states the bracket deflection limit that the slots permit as a deferred-submittal criterion. Runway end stops sit inboard of the runway-end tie saddle and are checked for nut clearance to it.

**Runway end stops** (Connections): when a crane stop force reaches the girder, design bolted stops near the girder ends, inboard of the top tie saddle, for the factored bumper force at the bumper height. The checks cover front-bolt tension with shear and slip, bolt bearing, no-prying thickness of the base plate and girder flange, stop flexure, shear, face bending between the stiffeners and of its outstand beyond them, the base plate welds, the stiffener-to-face-plate fillets (both sides of each stiffener over its full height, for the shear flow that makes the face plate and stiffeners act together and the bumper reaction each stiffener takes from the face plate), the bumper couple on the girder end span and far-support uplift, web local yielding and crippling under the heel, Category B fatigue at the stop holes, and the socket clearances: heavy hex heads on the base plate clear the toes of the face plate and stiffener fillets (bolt C/L to the plate face less the weld leg) by the AISC Manual Table 7-15 tightening clearance, and the nuts below the flange clear the bearing stiffeners, the top tie saddle and the web fillet. The demonstration stops use a 7 in gauge about 3 in stiffener centers (2 3/4 in on the capped W24X94 flange) and front bolts 1 3/4 in behind the face plate. The stiffeners reach at least the top of the bumper contact. The elevation, plan and section draw the heavy hex heads and nuts, the plan dimensions the front bolts to the face plate, the design data states the clearances to the weld toes, and the elevation, plan and section call the stiffener-to-face-plate fillets, which the stop notes require. Rail keepers start beyond the stops. Building-mounted stops remain by others.

**Runway beyond the model** (Geometry, simple spans): when only the bays around a new or replaced support are modeled, enter the existing bay length beyond each modeled end that the runway continues past. Crane travel may then extend onto those bays. Wheels on an adjacent bay load only the shared support. That existing girder's reaction, assuming the same girder, rail and dead load per length as the modeled bay, is added to the support reactions by load type, the design reaction, the bracket loads and the interface schedule, so a continued end support carries what it would as an interior support of the longer runway. End stops are placed only at true runway ends. The general arrangement S-01 draws the existing girders dashed with break lines and notes them as existing, to be field verified. The existing girder itself, its tie and its bearing are not checked. Continuous girders must still be modeled to their true ends.

**Adopted code** (Project & report settings): enter the building code adopted by the jurisdiction and whether it adopts the 2016 or the 2022 editions of AISC 360 and ASCE 7. The calculation applies AISC 360-16 and ASCE 7-16. S-00 and the calculation pages cite the adopted code. A package is issued for permit or construction only once the code is entered, and, for a 2022-edition jurisdiction, once the engineer of record confirms having reviewed the design against those editions.

Worksheet section **05 Existing building & supports** is for adding or replacing runway supports on an existing building. It lists unfactored support reactions by load type (D, L, crane Cd/Cv/Ci, side thrust Css, longitudinal Cls), downloadable as CSV. Enable **Check the existing column** to check the receiving column for those crane reactions plus its existing D, L, Lr, S, R, W and E effects under ASCE 7 combinations and AISC 360 compression, flexure, shear and H1 interaction, with a runway-level drift check. With a column bracket, the column section, eccentricity and flange unbraced length come from the bracket's surveyed receiving column. Enable **Check the bracing that carries crane traction and stop forces** to check the crane-level longitudinal braced bays (tension-only rod X, angle X or single angle) for crane traction or the crane stop force with the building's own wind and seismic forces. For an existing building, frame action, collectors, brace connections, anchors and foundations remain by others; between new freestanding columns the whole system is designed (see below). See [references/AIST_CHECKS.md](references/AIST_CHECKS.md).

### New freestanding runway columns

When the building cannot carry the crane, tick **New freestanding runway column designed here**. The column is a fixed-base cantilever across the runway (braced along it by the crane-level bracing) that carries the girder on its welded bracket and the top-flange tie at its face, with no existing building loads. Selecting its W shape sets the bracket's receiving column to match. The column must reach the tie and stop at or below the top of the girder, clear of the crane end trucks.

Enable **Design the base plate, anchor rods and spread footing** to check, at every support and for each ASCE 7 combination without wind or seismic (each crane case also taken with the least crane vertical load and full side thrust):

- base plate by AISC Design Guide 1: concrete bearing with A2/A1, small- or large-moment bearing block, compression-side and tension-side plate thickness, and the column-to-plate welds;
- headed cast-in F1554 rods by ACI 318-19 Chapter 17 at strength level: steel, concrete breakout, pullout and side-face blowout in tension; steel, breakout in each direction and pryout in shear; and the §17.8 interaction. Cracked concrete, Condition B, no anchor reinforcement;
- spread footing: service soil pressure (trapezoid, triangle or biaxial effective area); overturning (FS 1.5 about the edge, dead load only, with the runway dead reaction's eccentric moment deducted); sliding (FS 1.5); frost depth; ACI 318-19 one-way shear and flexure in each direction; two-way shear with moment transfer; minimum steel; bar spacing; and bar development.

Each check reports the support where it governs. Inputs are checked for clashes and drawing mismatches: plate washers against the column flange welds, washers on the plate, rod spacing, anchor heads above the bottom bars and cover, and the column base on its footing against the entered top-of-rail elevation. The footing top is entered below the floor (zero pours it flush with the saw cut slab). S-01 draws the new columns and footings as new steel, the bracket, flange tie and connection details call for shop welds to the new column, S-00 adds the foundation codes, materials and special inspections, and the new-column details (on the last detail sheet) draw the column, base plate and footing.

Tick **Design the new columns ... for seismic forces** to treat the new columns as an ASCE 7 cantilever column system (ordinary or special steel cantilever columns, Table 12.2-1) across the runway: Cs = SDS·Ie/R on the short-period plateau from the runway dead load, empty crane and column weight at the girder; the ASCE 7 seismic combinations on the column (with the 15% axial limit of §12.2.5.2, design drift and stability coefficient); and the overstrength Ωo combinations on the base plate, anchor rods and footing, with the ACI 318-19 §17.10.5.4 reduction on concrete-governed anchor tension in SDC C to F and FS 1.0 against overturning and sliding. The system, the 35-ft height limit, the SDC against SDS and the redundancy factor are validated. SDC A takes only the §1.4.2 force of 0.01W. Along the runway the crane-level bracing carries the seismic force. **Load new-column example** under Project loads a fictitious 2-ton runway on new W14X120 columns.

With **Check the bracing that carries crane traction and stop forces** enabled on new columns with their bases, the longitudinal system is designed here rather than left to others. Tick the braced spans (the middle span by default); the work points are the bearing seat and the top of the base plate, in one tier. The design covers:

- **rods**: tension-only rod X-bracing (J3.6 threaded rod and D2), with the AIST crane stop, traction and, with seismic design, the runway's own seismic force along it. The two rods of an X pass each other in parallel planes: the rod with its upper end at the lower-numbered column is on the column centerline, the other offset toward the girder by the strut web and a filler (in 1/16 in steps) so they are at least 1/4 in clear at mid-bay; the strut web lies between the two upper gussets. The checks add the clear gap, the strut lap eccentricity at the offset gusset (weak-axis plate bending and its fillets), the J5.2(b) filler reduction on the strut bolts, and the offset rod's torque on the column (added to the torsion check) and on the base (anchor torsional shear);
- **rod ends**: a forged clevis and pin on a gusset welded to the column web, all designed for the rod's available tensile strength so the connections develop the rod. The gusset is proportioned by AISC D5.2 and checked for pin double shear and bearing (J7), tension rupture on the effective width and block shear beyond the pin (D5.1), yield on its gross and Whitmore sections, its fillets to the web and base plate by the elastic method, and the column web out of its plane (yield-line strip). The weld lengths are the shortest that pass, from 6 in;
- **collector**: a crane-level W strut on the column centerline in every span, bolted to the gusset or a strut tab at each column, carrying the full line force (E3/E4 compression with its own weight by H1, slenderness, tension at the coped end, bolts, bearing and block shear, tab welds and web). Each girder's locating bearing bolts deliver its longitudinal force to the bracket seat, which a fillet welds to the column flange (checked with the in-plane couple), and with seismic design the locating bolts are checked for the bay's seismic force;
- **braced-bay columns and bases**: the brace overturning compresses the braced columns (in their H1 checks) and lifts and shears their bases along the runway (anchor rods, base plate, soil, overturning and sliding with the uplift deducted, and a footing uplift check). The girder offset at each locating column is a torque, taken by warping to the fixed base and added to H1 as flange lateral bending (New column · H1 with torsion), and on the anchor rods as torsional shear;
- **seismic along the runway**: a steel system not specifically detailed for seismic resistance (ASCE 7 Table 12.2-1 H, R = 3, Ωo = 3, Cd = 3, AISC 360 only, SDC A to C; SDC D to F is reported unsupported), from the runway dead load, empty cranes, columns and strut, with the design drift. Collectors and anchors take Ωo in SDC C;
- **separation** from the existing building by ASCE 7 §12.12.3, δMT = √(δM1² + δM2²), from the runway's inelastic displacement across it (columns with footing rotation) and along it (bracing) and the building's δM at the runway (entered with the seismic data, or the Table 12.12-1 allowable drift 0.025h as a bound).

The 'supporting-structure' and 'brace-by-others' items then drop out. S-01 draws the strut and the rods leaving the upper gussets on the girder elevation with the rod size callout, the strut and the braced spans (X) on the plan, the rods and strut in the isometric, and the required separation under the plan; the bracing details (braced bay elevation, the plans at both upper gussets of a braced span over two rows, the connections at the work points and at the base, and a section at mid-bay showing how the rods pass) and their design data and notes follow the new-column details. The column elevation shows the strut and rod gussets at the work point, the footing plan keys the footing section, and the anchor row of the design data gives the force on the tension row and on all rods, with the per-rod values.

## Capped runway design

Choose **I-girder with cap channel** under Geometry, select the AISC W and C/MC shapes, and complete **Cap material & attachment**. Live checks include conservative F5 flexure for both bending signs, separate flange lateral resistance, E4/E7 compression, shear-center-based torsion/warping, cap weld shear flow and end development, and weld/base-metal fatigue. The channel web alone carries the local keeper bending check. Full contact, continuous full-length welds and unperforated top elements are required; CMAA E/F and unsupported geometries stay gated.

**Load capped example** opens a separate fictitious 2-ton, three-bay W24X94 + C15X33.9 example. It is not a replacement section for the 10-ton rolled example. Generate output includes four ARCH D (36 x 24 in) sheets: the cover, the general arrangement and two detail sheets with the connections, cap attachment, independent supports, welded brackets, direct flange ties and runway end stops, with the drawing set DXF. The revised tie layout and local saddle checks resolve the detected static hardware clashes, and the tie movement checks cover end rotation, thermal travel and support deflection; the global building interface remains separate. See [capped design basis and verification](references/CAPPED_DESIGN.md), including the explicit difference from the historical published Cw table.
